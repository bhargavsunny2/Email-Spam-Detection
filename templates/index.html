💡 About This Project

The Email Spam Detection System is a Machine Learning application that identifies whether an email message is spam or normal. It uses Natural Language Processing and the Naive Bayes algorithm.

Python Flask Machine Learning Naive Bayes TF-IDF HTML CSS

How It Works

  1. User enters an email message.
  2. TF-IDF converts the message into numerical features.
  3. Naive Bayes predicts the message category.
  4. The website displays the prediction result.
